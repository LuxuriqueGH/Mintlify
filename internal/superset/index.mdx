The Superset/Preset.io system is the BI layer for Luxurique analytics. It connects to Supabase as a read-only `preset_ro` role and owns no schema or data — only connection wiring, dashboard/chart definitions, and docs.

This wiki covers how the system is wired, how definitions are provisioned, and how the exchange workflow keeps the repo in sync with the live Preset workspace.
