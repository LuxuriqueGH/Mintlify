## What it does (summary)

Introspects both Twenty GraphQL endpoints (`/metadata` admin API and `/graphql` runtime data API) and writes three JSON dumps to `schemas/twenty/` in the `../../../Twenty/` repo. Run on demand to keep slugs accurate after any Twenty object/field changes.

See the `../../../Twenty/` repo for full usage, configuration, and gotchas.
