# qc-web

Webapp rebuild of the Luxurique Quotation and Costing Engine (QC Sheet), replacing the Excel VBA workbook in `../QuotationCostingEngine`.

**Status: spec stage — nothing built yet.**

- [SPEC.md](SPEC.md) — architecture, decisions, phased plan
- [BACKLOG.md](BACKLOG.md) — work items by phase
- [CLAUDE.md](CLAUDE.md) — agent orientation + cross-repo pathways

Stack (agreed 2026-08-17): static React SPA (Vite + TypeScript + TanStack + Tailwind) on Cloudflare Pages + one Supabase project (Postgres/RLS, M365 SSO, Storage, Realtime). No self-operated servers.
