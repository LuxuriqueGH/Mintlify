SupplierDB is the domain system for migrating messy SharePoint supplier lists into Twenty CRM. Source rows jumble three entity types together (Companies, People, and Resources). SupplierDB defines what each one is so the untangling stays honest to reality.

Stage one migrates People and Companies cleanly. Resources are deferred to a later stage. The system includes a deduplication pipeline, Twenty upload mapping, and schema reference artifacts.
