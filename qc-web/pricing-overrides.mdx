The standard pricing chain — cost → markup → margin → commission → unit price — covers the vast majority of quotations. When you need to depart from that chain for a specific row or group, the QC Webapp provides a set of **pricing overrides** that SL+ users can apply. Each override is precise: it replaces or removes exactly one step of the chain while leaving the rest intact.

## Row-level overrides

You can apply overrides to an individual ungrouped line item from the **row side panel**. Open the side panel via the row-menu icon at the left of any row.

<CardGroup cols={2}>
  <Card title="Markup Rate Override" icon="percent">
    Replaces the standard markup rate for this row. The QC rate table rate becomes inactive while the override is in force. An explicit value of **0** means 0% markup — no markup is applied. Clear the field to restore the standard rate.
  </Card>
  <Card title="Marked-Up Cost Override" icon="circle-dollar-to-slot">
    Sets the row's marked-up cost directly, bypassing both the cost value and the markup step. Margin and commission still apply on top of this figure unless the skip flags are also set. Must be ≥ 0.
  </Card>
</CardGroup>

<Warning>
  You cannot set both a **markup rate override** and a **marked-up cost override** on the same row — choose one. Clear the existing override before applying the other.
</Warning>

### Skip flags

Two flags let you remove margin or commission from the pricing chain for a specific row:

| Flag | Effect |
|------|--------|
| **Skip margin** | Margin is not applied when calculating the unit price for this row. |
| **Skip commission** | Commission is not applied when calculating the unit price for this row. |

Both flags are SL+ only and can be set independently. They apply after markup and before the ¥100 rounding step.

## Group-level overrides

When a row belongs to a group, the **group** is the priced unit. Row-level price overrides (marked-up cost override, skip margin, skip commission) are not available on grouped rows — they belong to the group instead. Open the **group side panel** from the group header row's menu to access these fields.

<CardGroup cols={2}>
  <Card title="Markup Rate Override (group)" icon="percent">
    Applies a single markup rate to the group's total cost (the sum of active cost × quantities across all active member rows), replacing each member's individual markup. Member markups become inactive while the group override is in force. For category/label breakdown views, the marked-up cost is allocated back to members proportionally to their cost contribution (equal split if total cost is zero).
  </Card>
  <Card title="Marked-Up Cost Override (group)" icon="circle-dollar-to-slot">
    Sets the group's marked-up cost directly. The same mutual-exclusivity rule applies: you cannot set both a markup rate override and a marked-up cost override on the same group — choose one.
  </Card>
</CardGroup>

<Warning>
  You cannot set both a **markup rate override** and a **marked-up cost override** on the same group — choose one. Clear the existing override before applying the other.
</Warning>

The **Skip margin** and **Skip commission** flags are also available at the group level, with the same effect as at the row level.

<Note>
  When a row's group carries a pricing override, the row's own markup rate override becomes **inactive** — it is stored safely but has no effect until the row is removed from the group or the group's override is cleared.
</Note>

## Protect overrides

Each QC has a **Protect overrides** setting, which is **on by default**. When this setting is on, moving a row into or out of a group that carries a pricing override requires **SL+ access**. This prevents accidental changes to carefully priced groups.

You can find this setting in the QC header panel. SL+ users can toggle it on or off for the entire QC.

Additionally, each group has its own **Override protection** flag that can override the QC setting for that group specifically:

| Group flag state | Behaviour |
|-----------------|-----------|
| **Not set** | The group follows the QC's Protect overrides setting. |
| **On** | Membership changes to this group always require SL+, regardless of the QC setting. |
| **Off** | Membership changes to this group are unrestricted, regardless of the QC setting. |

<Warning>
  If someone changes the membership of a group that carries an override and the group was **not** protected at the time, the system records a **trample notice**. The user who originally set the override receives an inbox notification, and the group shows a trample warning until it is dismissed by a senior user or until the override is cleared.
</Warning>

## Override visibility

The grid uses visual markers to distinguish overridden values from standard calculated values. Any cell whose value comes from an override (rather than the standard chain) is displayed with a distinct style so you can see at a glance which rows or groups have been manually adjusted.

<Tip>
  To audit which rows in a QC carry overrides, use the row history drawer or the per-tab breakdown panel, which highlights override-driven figures in the category/label totals.
</Tip>

## Clearing an override

To restore standard pricing on a row or group:

<Steps>
  <Step title="Open the side panel">
    Click the row-menu or group-menu icon to open the side panel for the item you want to restore.
  </Step>
  <Step title="Locate the override field">
    Find the markup rate override or marked-up cost override field that is currently set.
  </Step>
  <Step title="Clear the field">
    Delete the value and save. The row or group immediately resumes calculating from the standard chain — the QC rate table rate is restored and the row is repriced automatically.
  </Step>
</Steps>
