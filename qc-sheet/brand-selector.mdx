The QC Sheet supports three client-facing brands, each with its own quotation layout, embedded Word template, and PDF disclaimer page. Before you build or export a quotation, confirm that the correct brand is selected — the brand controls every output the QC Sheet produces, from the on-screen staging layout right through to the printed disclaimer.

## The three brands

<CardGroup cols={3}>
  <Card title="Luxurique (LUX)" icon="star">
    The flagship brand. Uses the Luxurique quotation layout, the LUX Word template, and the LUX disclaimer page.
  </Card>
  <Card title="Luxurique Travel (LXT)" icon="plane">
    Shares the same table layout structure as Luxurique, but has its own Word template and its own distinct disclaimer page — so your exported content differs from LUX even though the table layout looks identical.
  </Card>
  <Card title="Liberty (LBT)" icon="shield">
    Fully independent layout, Word template, and disclaimer page. All three outputs are specific to the Liberty brand.
  </Card>
</CardGroup>

## Selecting a brand

1. Open the **Quotation** ribbon group (the **Costing** tab in the Excel ribbon).
2. Click the **Template** dropdown.
3. Select **Luxurique**, **Luxurique Travel**, or **Liberty**.

The QC Sheet saves your selection immediately to the workbook's document properties, so the chosen brand persists the next time you open the file — even across VBA resets.

<Tip>
  You can confirm the active brand at any time by glancing at the **Template** dropdown; it always reflects the currently saved selection.
</Tip>

## How brand affects each export type

| Export | What the brand controls |
|---|---|
| **Update Quotation** | Which quotation layout sheet is rebuilt |
| **Export PDF (A4 / A3)** | Which rebuilt layout is printed, including its disclaimer page |
| **Export Word** | Which embedded Word template is extracted and populated |
| **Export XLSX** | Which quotation sheet is copied into the sanitised workbook |

## LXT and LUX layout sharing

Luxurique Travel uses the same table layout structure as Luxurique — the same header block and the same per-section quote table prototype. However, LXT has its own Word template and its own dedicated disclaimer page. The disclaimer is never shared with or combined with the LUX disclaimer.

<Note>
  If you switch brands after running **Update Quotation**, run **Update Quotation** again before exporting. The rebuild targets the active brand's sheet; an export triggered without a fresh rebuild for the new brand will rebuild automatically, but triggering it manually first lets you review the layout before committing to a PDF or Word file.
</Note>

## Brand and the disclaimer page

Each brand has its own dedicated disclaimer page. When you run **Update Quotation**, the rebuild appends only the disclaimer for the active brand — it always starts on a new printed page. If a brand's disclaimer has not been configured in the workbook, that brand's output will have no disclaimer page and no error is raised.

<Warning>
  Do not remove or alter the disclaimer content for any brand in the workbook. A missing disclaimer means it will be silently omitted from every PDF and Word export for that brand.
</Warning>
