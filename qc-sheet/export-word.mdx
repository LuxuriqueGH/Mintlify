The QC Sheet can export your quotation data into a fully formatted Microsoft Word document, ready for further editing or direct delivery to the client. The export uses a branded `.docx` template embedded in the workbook for each of the three brands — Luxurique, Luxurique Travel, and Liberty — so the layout, fonts, and logo are already in place when the document opens.

Word stays open after the export, giving you immediate access to review or refine the document before sending it.

## Before you export

Check the following before you begin:

- **Microsoft Word must be installed** on your computer. The export uses Word directly to build the document; it will not work without a local Word installation.
- **A Word template must be embedded for the active brand.** Each brand (Luxurique, Luxurique Travel, and Liberty) requires its own template embedded in the workbook. If no template has been embedded yet for the brand you want to use, see [Embedding a Word template](#embedding-a-word-template) below.
- The workbook must be saved to disk before running the export.
- The **Overview** sheet has current project fields — client name, dates, PAX count, and totals — as these are written into the Word document's static fields automatically.

<Tip>
You do not need to run a manual rebuild before exporting. The export checks whether the quotation data is current and rebuilds automatically if needed. If you want to force a full rebuild first, click **Update Quotation** on the ribbon.
</Tip>

## Exporting the Word document

<Steps>
  <Step title="Select the active tab">
    Navigate to the costing tab that corresponds to the quotation set you are exporting. The export builds the Word document from the quotation tables for the active costing tab.
  </Step>
  <Step title="Choose the brand template">
    In the ribbon's **Quotation** group, open the **Template** dropdown and select the correct brand: **LUX** (Luxurique), **LXT** (Luxurique Travel), or **LBT** (Liberty). The export uses the Word template embedded for that brand.
  </Step>
  <Step title="Click Export Word">
    Click **Export Word** on the ribbon. The workbook will:
    1. Check whether the quotation layout is current and rebuild if needed.
    2. Extract the embedded Word template for the active brand to a temporary file.
    3. Open Word (or attach to a running instance) and load the template.
    4. Populate the static fields — project name, client name, dates, PAX, totals, and fees.
    5. Clone the data table prototype once for each active quotation section, filling in item descriptions, quantities, and prices.
    6. Save the completed document to your Desktop and make Word visible.
  </Step>
  <Step title="Review the document in Word">
    Word opens with the completed document active. Review the layout, static fields, and item tables before making any manual adjustments or sending the file to the client.
  </Step>
</Steps>

## Output file name and versioning

The Word document is saved to your Desktop with a name based on the workbook filename and today's date:

```
<WorkbookName>_Word_YYMMDD.docx
```

If a file with that name already exists, the export appends a version suffix automatically:

```
<WorkbookName>_Word_YYMMDD_v2.docx
<WorkbookName>_Word_YYMMDD_v3.docx
```

<Note>
The Desktop path is resolved correctly even when your Desktop is redirected to OneDrive.
</Note>

## Brand templates

Each of the three brands has its own Word template, stored separately inside the workbook:

| Brand code | Brand name |
|---|---|
| **LUX** | Luxurique |
| **LXT** | Luxurique Travel |
| **LBT** | Liberty |

The templates are independent — re-embedding a template for one brand does not affect the others.

## Embedding a Word template

If no template has been embedded for the active brand, the export will prompt you to add one. You only need to do this once per brand (or whenever the template design is updated).

<Steps>
  <Step title="Select the correct brand">
    In the ribbon's **Quotation** group, open the **Template** dropdown and select the brand whose template you want to embed.
  </Step>
  <Step title="Click Import Template on the ribbon">
    Click the **Import Template** button on the ribbon. A file picker opens.
  </Step>
  <Step title="Select the .docx file">
    Browse to the Word template `.docx` file for this brand and select it. The template is embedded into the workbook and stored per-brand. Only the active brand's template is replaced; other brands are untouched.
  </Step>
  <Step title="Save the workbook">
    Save the workbook to persist the embedded template. The export will now find the template automatically for this brand.
  </Step>
</Steps>

<Warning>
The Word export requires Microsoft Word to be installed and accessible on your computer. If Word is not available, the export will fail with an error. The export also leaves Word running after completion — if you had Word open with other documents, those documents are not affected.
</Warning>

<Note>
If the export completes but the document is missing content, Word will stay open with the partial document so you can inspect what was built. A message will describe what could not be populated.
</Note>
