The QC Sheet gives you two levels of organisation above the individual line item: **sections** and **groups**. Sections are titled headings that divide your quote set into logical parts (Day 1, Ground Transport, Pre-Tour, etc.). Groups are clusters of related rows that always travel together when you sort or reorder the table.

Understanding the difference between the two is key to keeping large quote sets tidy and easy to read.

## Sections

A **section** is a user-defined heading that groups a set of rows under a title. Every active quote-set tab always has at least one section — the QC Sheet enforces this, so you cannot accidentally end up with a table that has no section headings.

### How sections appear in the table

Each section starts with a **title row** — a special header row that displays the section name. All rows between one title row and the next belong to that section. When you sort the table, rows stay within their own section (provided the **Maintain Section Order** toggle is on — see below).

### Creating a section

1. Click any data row (or select a range of rows) where you want the new section to begin.
2. In the **Luxurique ribbon**, click **Create Section**.
3. A new title row is inserted above your selection, and the selected rows move into the new section.

The QC Sheet names the new section "Section N" automatically. Click the title row's **Item** cell to rename it to something meaningful (e.g. "Day 1 – Arrivals", "Shore Excursions").

<Tip>
When you click a single row inside an existing section, the **Create Section** action adopts all the rows below your click point (within the same parent section) into the new section. If you select multiple rows first, only those rows move into the new section — the parent section retains the rest. This lets you carve out a sub-section precisely.
</Tip>

### Dissolving a section

To remove a section heading and merge its rows into an adjacent section:

1. Select any row within the section you want to dissolve.
2. In the ribbon, click **Remove Section**.
3. Confirm the action in the dialog. The dialog tells you which neighbouring section the rows will be merged into.

The title row is deleted and all rows are merged into the nearest neighbouring section. You cannot dissolve a section if it is the last user section in the table — the QC Sheet will block the action and prompt you to keep at least one section.

<Warning>
You cannot dissolve the **Cancelled** section. That section is managed automatically by the QC Sheet and cannot be removed or reorganised manually.
</Warning>

## The Maintain Section Order toggle

The **Maintain Section Order** toggle in the ribbon controls what happens when you sort the table:

- **ON (default):** Rows stay within their section when sorted. Sorting by date, for example, reorders rows within each section without mixing items from different sections together.
- **OFF:** All rows can sort freely across the entire table. Sections may interleave. Use this mode only if you intentionally want to flatten the section structure.

<Note>
Leave Maintain Section Order **on** for day-to-day quoting work. Turning it off is an advanced option intended for specific reordering tasks.
</Note>

## Groups

A **group** links two or more related rows into a single unit. Grouped rows always sort and move together — you cannot accidentally split them by sorting the table or using the Move Up / Move Down ribbon buttons.

### When to use a group

Use groups when multiple line items represent different components of the same service and must always appear together in sequence. For example:

- Three transfers that together make up an airport shuttle run
- An accommodation row paired with a compulsory meal supplement

The **Group** column (column A) displays the group membership in plain language, such as **"1 of 3"**, **"2 of 3"**, **"3 of 3"** — making it immediately obvious which rows belong together and how many rows are in the group.

### Grouping rows

1. Activate the rows you want to group (each must have an Item ID — i.e. the Include checkbox must be ticked).
2. Select all the rows you want in the group.
3. In the ribbon, click **Group Rows**.

The QC Sheet links all selected rows together and numbers each one in sequence within the group. The Group column text updates to "X of N" format automatically.

<Tip>
If you select rows that already belong to a group plus some ungrouped rows, the QC Sheet will merge the ungrouped rows into the existing group rather than creating a second group. This means you can build up a group incrementally by adding rows one at a time.
</Tip>

### Ungrouping rows

1. Select the rows you want to ungroup.
2. In the ribbon, click **Ungroup Rows**.

Each row becomes independent. The rows remain activated and in the table — they just no longer move together as a unit.

### Moving groups

Use the **Move Up** and **Move Down** buttons in the ribbon to reposition groups within the table. The entire group always moves as one, regardless of how many rows it contains. When Maintain Section Order is on, groups cannot be moved across section boundaries using these buttons.

## The auto-Cancelled section

Any row whose **Status** is set to `Cancelled` is automatically reassigned to a special **Cancelled** section at the bottom of the table. This section is created by the QC Sheet when the first cancelled row appears, and it is sorted to the end of the table automatically. You do not need to manage it manually.
